# Task 3 data — Monet paintings + photos
Use the `dataset.zip` provided on Canvas (Files → Labs → Fall 2026 Lab1 → Part3). Unzip it and move the two
folders here, so you have:

    task3_gan/data/monet_jpg/   (300 paintings, 256x256)
    task3_gan/data/photo_jpg/   (7,038 photos, 256x256)

Ignore the `__MACOSX/` folder and `.DS_Store` files in the zip (the code skips hidden files anyway).
Raw data is not pushed to GitHub. The Drive link to the zipped dataset is listed in the main README.

The team-fixed held-out/audit photo list is `task3_gan/common/team_eval_split.json` (created on the first run, then committed).
